# بوت تسجيل الحضور — Discord

بوت حضور لأعضاء العصابة بنفس نظام اللوحة:

- **تسجيل دخول** — يحفظ وقت البداية
- **تسجيل خروج** — يحسب الساعات والدقايق ويضيفها لمجموع الأسبوع
- **عرض الحضور** — يشوف مين مسجل دخول حالياً
- **لوحة أدمن** — تشوف ساعات الجميع وتصفرها
- **موسيقى يوتيوب** — تشغيل من الشات مع تحكم بالصوت

## أوامر الحضور

| الأمر | الوظيفة |
|--------|---------|
| `/حضور` | نشر لوحة الأزرار في الروم (أدمن) |
| `/ساعاتي` | يشوف ساعاتك هذا الأسبوع |
| `/لوحة عرض` | لوحة تحكم الأدمن |
| `/لوحة الاسبوع` | ساعات الجميع هذا الأسبوع |
| `/لوحة عضو` | ساعات عضو محدد |
| `/لوحة اخراج-عضو` | إزالة عضو من المسجلين دخول واحتساب مدته |
| `/لوحة تصفير-عضو` | تصفير ساعات عضو |
| `/لوحة تصفير-الكل` | تصفير ساعات الجميع |

## أوامر الموسيقى (في الشات)

ادخل روم صوتي أول، بعدين اكتب في أي شات:

| الأمر | الوظيفة |
|--------|---------|
| `ش اسم الأغنية` | بحث وتشغيل من يوتيوب |
| `تخطي` | تخطي الأغنية الحالية |
| `وقف` | إيقاف ومغادرة الروم |
| `باوس` | إيقاف مؤقت |
| `كمل` | متابعة التشغيل |
| `صوت 50` | تعديل الصوت (0-100) |
| `قائمة` | عرض قائمة الانتظار |
| `الحين` | الأغنية الحالية |
| `موسيقى` | عرض أوامر الموسيقى |

## إعداد البوت (مرة واحدة)

### 1) إنشاء تطبيق Discord

1. ادخل [Discord Developer Portal](https://discord.com/developers/applications)
2. **New Application** → سمّه اللي تبيه
3. من تبويب **Bot** → Reset Token وانسخ التوكن
4. من نفس تبويب **Bot** فعّل:
   - **Message Content Intent** (مهم للموسيقى)
5. من تبويب **OAuth2 → URL Generator**:
   - Scopes: `bot` + `applications.commands`
   - Bot Permissions: `Send Messages`, `Use Application Commands`, `Embed Links`, `Connect`, `Speak`
6. افتح الرابط وأضف البوت لسيرفرك

### 2) جمع الـ IDs

فعّل Developer Mode في الدسكورد (Settings → Advanced)، بعدين:

- انسخ **Application ID** من البورتال → `CLIENT_ID`
- كلك يمين على السيرفر → Copy Server ID → `GUILD_ID`
- كلك يمين على نفسك → Copy User ID → `ADMIN_IDS`

### 3) ملف البيئة

```bash
copy .env.example .env
```

عدّل `.env` وحط القيم الحقيقية.

### 4) تشغيل

```bash
npm install
npm run deploy
npm start
```

بعدها اكتب `/حضور` في الروم اللي تبيه عشان تنزل اللوحة بالأزرار.

## ملاحظات

- البيانات تنحفظ في `data/attendance.json`
- لوحة الأدمن للمسجلين في `ADMIN_IDS` أو اللي عندهم صلاحية Administrator
- عند الخروج أقل مدة تحسب دقيقة واحدة
- التصفير يصفّر مجموع الأسبوع فقط، وما يطلع اللي مسجلين دخول حالياً

## الإزالة التلقائية عند الغياب

إذا فيه عضو مسجل دخول وما هو داخل أي روم صوتي داخل السيرفر لمدة `ABSENT_HOURS` (افتراضي 2)، البوت:
- يشيله من المسجلين دخول (وما يحتسب له هالوقت)
- يرسل تحذير تلقائيًا في روم لوحة الحضور

للتحكم بالاستثناءات:
- `/لوحة استثناء-عضو`
- `/لوحة الغاء-استثناء-عضو`
- `/لوحة استثناء-قائمة`
